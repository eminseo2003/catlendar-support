Catlendar – 앱 지원 페이지

1️⃣ 앱 소개

Catlendar는 학습과 일상을 체계적으로 관리할 수 있는 일정·할 일 관리 앱입니다. 하루, 주간 단위로 계획을 정리하고 분석까지 한 번에 할 수 있도록 설계되었습니다.

복잡한 기능 대신, 지금 해야 할 일에 집중할 수 있는 구조를 제공합니다.

2️⃣ 주요 기능

✅ 일정 관리

  • 일간 / 주간 시간표 관리
  • 날짜별 일정 추가 및 수정
  • 한눈에 보는 시간 흐름

✅ 할 일(To-Do) 관리

  • 오늘 / 이번 주 해야 할 일 정리
  • 일정과 할 일을 함께 또는 분리해서 확인
  • 체크 기반 진행 상황 관리
  • 반복 할 일(매일·요일·매주)과 세부 단계
  • 중요 할 일 ★ 표시, 못 한 할 일 내일로 옮기기

✅ 유연한 화면 구성

  • 스크롤 / 세그먼트 / (태블릿·맥) 양옆 분할 보기 지원
  • 사용자 설정에 따른 화면 구성 커스터마이징
  • 원하는 강조색 고르기

✅ 공부 타이머

  • 스톱워치와 뽀모도로(집중·휴식 시간 설정, 휴식 후 자동 시작)
  • 카테고리·할 일·세부 단계를 골라 기록
  • 공부 기록을 일별·주별 일정으로 남기기, 필요 없으면 기록 버리기

✅ 시험 관리

  • 시험 D-day 표시
  • 시험 공부 계획 만들기와 진행 막대
  • 목표 점수·받은 점수 기록

✅ 위젯과 알림

  • 홈 화면 위젯(오늘 할 일·오늘 공부 시간·가까운 D-day)
  • 잠금화면 타이머(라이브 액티비티)
  • 아침 일정 알림, 뽀모도로 알림

✅ 분석 기능

  • 일간 / 주간 기준 할 일 수행 분석
  • 색상 기반 일정 분포 분석
  • 스스로의 계획 패턴을 돌아볼 수 있는 시각화 제공
  • 공부 기록: 날짜·카테고리별 공부 시간, 연속 공부 일수, 하루·이번 주 목표, 1년 공부 잔디
  • 주간 돌아보기와 공부 기록 내보내기(CSV)

3️⃣ 로그인 및 계정

Catlendar는 간편하고 안전한 로그인 방식을 제공합니다.

  • Apple 로그인
  • Google 로그인
  • 카카오 로그인
  • 이메일 로그인 (이메일 인증번호로 가입, 비밀번호 재설정 메일 제공)

👉 Apple·Google·카카오는 별도의 회원가입 없이 바로 사용 가능

👉 계정 삭제 기능 제공 (설정 화면에서 직접 가능)

4️⃣ 데이터 보안 및 개인정보 보호

Catlendar는 최소한의 정보만 수집합니다.

🔐 수집하는 정보

  • 사용자 식별자(UID)
  • 이메일 주소 (Apple / Google / 카카오 / 이메일 로그인 시)
  • 이름(displayName, 로그인 제공자에서 전달된 경우)
  • 카카오 회원번호 (카카오 로그인 시)
  • 사용자가 직접 입력한 일정, 할 일, 시험 정보
  • 공부 기록 (공부한 시간, 카테고리, 메모)

❌ 수집하지 않는 정보

  • 전화번호
  • 주소
  • 위치 정보
  • 결제 정보
  • 광고 식별자(IDFA)

모든 데이터는 서비스 제공 목적 외에는 사용되지 않습니다.

5️⃣ 계정 삭제 안내

사용자는 언제든지 앱 내 설정 화면에서

계정 및 관련 데이터 전체 삭제를 요청할 수 있습니다.

  • Firebase Authentication 계정 삭제
  • Firestore에 저장된 사용자 데이터 전체 삭제 (서버에서 한 번에 처리)
  • 카카오 로그인 연결 해제, Apple 로그인 연결 해지
  • 탈퇴 전 본인 확인을 위해 다시 로그인을 요청할 수 있습니다
  • 카카오 계정 설정에서 Catlendar 연결을 끊는 경우에도 계정과 데이터가 자동으로 삭제됩니다
