개인정보 처리방침

1. 수집하는 개인정보 항목

앱은 서비스 제공을 위해 아래와 같은 개인정보를 수집할 수 있습니다.

① 로그인 시

  • 사용자 고유 식별자(UID)
  • 이메일 주소 (Apple / Google / 카카오 로그인 시 제공되는 경우, 이메일 로그인 시 사용자가 입력한 경우)
  • 이름(표시명, Apple / Google / 카카오 로그인 시 제공되는 경우 또는 사용자가 입력한 경우)
  • 카카오 회원번호 (카카오 로그인 시)
  • 비밀번호 (이메일 로그인 시, Firebase Authentication이 암호화하여 보관하며 앱 개발자는 원문을 볼 수 없음)
  • 로그인 제공자 정보 (Apple, Google, 카카오, 이메일)

② 서비스 이용 과정에서 생성되는 정보

  • 일정 정보 (일정 제목, 시간, 날짜 등)
  • 할 일(To-Do) 정보 (세부 단계, 반복 설정 포함)
  • 시험 정보 (시험 이름, 날짜, 목표 점수·받은 점수)
  • 공부 기록 (공부한 시간, 카테고리·할 일, 메모)
  • 앱 설정 (뽀모도로 시간, 공부 목표, 강조색 등)
  • 사용자가 직접 입력한 기타 콘텐츠

※ 홈 화면 위젯과 잠금화면 타이머에 보이는 정보는 기기 안에서만 처리되며 외부로 전송되지 않습니다.

※ 앱은 전화번호, 주소 등 민감한 개인정보는 직접 수집하지 않습니다.

※ 이름과 이메일은 로그인 제공자(Apple, Google, 카카오)를 통해 전달되거나 사용자가 직접 입력한 정보로,

계정 식별 및 서비스 제공 목적으로만 사용됩니다.

2. 개인정보 수집 방법

  • Apple 로그인
  • Google 로그인
  • 카카오 로그인
  • 이메일 회원가입 및 로그인
  • 사용자가 앱 내에서 직접 입력

3. 개인정보 이용 목적

수집한 개인정보는 다음 목적을 위해 사용됩니다.

  • 사용자 인증 및 로그인 기능 제공
  • 이메일 회원가입 인증번호 및 비밀번호 재설정 메일 발송
  • 공부 기록 및 할 일 수행 분석 제공
  • 일정 및 할 일 데이터 저장·관리
  • 사용자별 맞춤 서비스 제공
  • 서비스 안정성 확보 및 오류 개선

4. 개인정보 보관 및 처리

  • 모든 개인정보는 Firebase Authentication 및 Firebase Firestore를 통해 안전하게 저장·관리됩니다.
  • 개인정보는 서비스 제공에 필요한 최소한의 기간 동안만 보관됩니다.

5. 개인정보 보유 및 이용 기간

  • 사용자가 계정을 유지하는 동안 개인정보를 보관합니다.
  • 사용자가 계정 탈퇴를 요청할 경우, 관련 개인정보와 일정·할 일·공부 기록 등 모든 데이터는 지체 없이 삭제되며, 카카오·Apple 로그인 연결도 해제됩니다.
  • 카카오 계정 설정에서 Catlendar 연결을 끊는 경우에도 계정과 데이터가 자동으로 삭제됩니다.
  • 이메일 인증번호는 10분, 비밀번호 재설정 링크는 30분이 지나면 더 이상 사용할 수 없습니다.

6. 개인정보 제3자 제공

앱은 이용자의 개인정보를 외부에 제공하지 않습니다.

다만, 아래 서비스 제공을 위해 필요한 경우에 한해 처리됩니다.

  • Google Firebase (인증 및 데이터 저장)
  • 카카오 (카카오 로그인 및 연결 해제)
  • Google Gmail (인증번호·비밀번호 재설정 메일 발송)

7. 개인정보 처리 위탁

앱은 원활한 서비스 제공을 위해 아래와 같이 개인정보 처리를 위탁하고 있습니다.

수탁자위탁 내용
Google Firebase사용자 인증, 데이터 저장
카카오카카오 로그인 인증 및 연결 해제
Google Gmail회원가입 인증번호·비밀번호 재설정 메일 발송

8. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 개인정보 열람 요청
  • 개인정보 수정 요청
  • 개인정보 삭제 요청 (계정 탈퇴)

👉 앱 내 [설정 > 계정 탈퇴] 기능을 통해 직접 삭제할 수 있습니다.

  • 인증된 사용자만 데이터 접근 가능
  • 불필요한 개인정보 수집 금지
